# My design philosophy

1. Always use state-of-the-art tooling
2. Use issue tracking system (Jira). Create tasks, and link branches and commits to them. It allows to present traceability and work load at-a-glance.
3. Test drive Work Instructions and SOPs before releasing them into QMS
4. Use controlled environment  to produce consistent complied binaries.
5. Come up with a good CAD sheet templates and release process before releasing many projects, to avoid correcting minor mistake in each of them after release. Especially watch out for page frame templates etc, which are replicated across many documents.
6. Identify applicable standards (safety, normative, etc) before starting work
