# My design philosophy

1. Always use state-of-the-art tooling (but beware of tools which are evolving _too_ fast)
2. Identify applicable standards (safety, normative, etc) _before_ starting work
3. Use issue tracking system (Jira et al). Create tasks, and link branches and commits to them. 
It allows to present traceability and work load at-a-glance.
4. Use controlled environment (Docker et al) to avoid "works on my machine"
5. Test drive Work Instructions and SOPs before releasing them into QMS
6. Come up with a good CAD sheet templates and release process(es) before releasing many projects, to avoid correcting minor mistake in each of them after release. Especially watch out for page frame templates etc, which are replicated across many documents.
